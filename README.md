A lightweight, joke/utility C++ tool that synchronizes and formats song lyrics into a dedicated memory block, turning **Memory Viewer** into a live karaoke display.

---

```text
 +------------------------------------------------------------------------------------------+
 | Cheat Engine - Memory Viewer                                                      [X]    |
 +------------------------------------------------------------------------------------------+
 |  Address          Hex View                         ASCII / Lyrics                        |
 |  --------------------------------------------------------------------------------------  |
 |  0x0000021A4B00   42 61 7A 65 6E 20 62 61 6E ...   Bazen bana gelir, gider seni dert...  |
 |  0x0000021A4B20   53 65 6E 69 20 72 C3 BC 79 ...   Seni rüyalarımda hapsetmeler          |
 |  0x0000021A4B40   59 C4 B1 6C 64 C4 B1 7A 6C ...   Yıldızların hırsızları mı var?        |
 |  0x0000021A4B60   54 75 74 61 6D 61 6D 2C 20 ...   Tutamam, tutamam, hep yeni bir gün... |
 +------------------------------------------------------------------------------------------+
```
